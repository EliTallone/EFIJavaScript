# EFI Frontend - Entrega

Proyecto frontend para la práctica profesionalizante I (EFI) usando React y React Bootstrap.

## Estructura
- src/: código fuente
- index.html
- package.json

## Cómo empezar
1. npm install
2. Crear .env con VITE_API_BASE_URL apuntando a tu API Flask (ej: http://localhost:5000/api)
3. npm run dev
